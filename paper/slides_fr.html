Le LM, qui n'a jamais vu de cinétique, place-t-il l'écart structural prédit au bon endroit ?

Verdict honnête

✓ Ce qu'on a montré (défendable)

  • DRfold2 place le contact 3D P1.1 ↔ P1 (~13 Å) correctement dans sa structure prédite.
  • Il propage la mutation single-nt à travers ce contact de manière spécifique (0/20 NULLs aléatoires, pemp = 0.048).
  • Protocole de probing reproductible (~30 min, ~0.30 €).

✗ Ce que ce n'est pas

  • Pas une découverte biologique. Mécanisme déjà Skilandat 2016.
  • Pas une preuve que le LM comprend. L'explication parsimonieuse : bonne géométrie + propagation locale.
  • Pas de test expérimental d'activité fait par nous.

Cross-check AlphaFold 3 — l'observation reportée

Les 7 séquences soumises au AlphaFold Server (gratuit, default settings). Ce qu'AF3 lui-même rapporte :

pLDDT AF3 ≈ 25

Sur les 7 séquences, AF3 sort une confiance moyenne de ~25 / 100. Le seuil ``low confidence'' est 50. AF3 lui-même signale : « je ne sais pas ».

R1107 ↔ R1108 (1 nt de diff.)

DRfold2 : ~1.86 Å RMSD global.
AF3 : ~13 Å RMSD global, et Δ@9 = 39 Å. Deux folds incompatibles pour 1 nt de différence.

Top-5 résidus divergents

DRfold2 : {9, 22, 24, 51, 60} (le P1).
AF3 : {1, 8, 9, 10, 11} (extrémité 5′). Seul résidu en commun : 9.

Lecture honnête : AF3 sur ce ribozyme orphelin court (~69 nt, sans MSA exploitable) n'est pas dans un régime utilisable. Le protocole révèle ce régime — c'est en soi reportable. Pas d'interprétation biologique tirée d'AF3.

Le lien NLP / transformers

1. Probing par micro-perturbation

Comme on demande à BERT « as-tu appris la syntaxe ? » via un swap d'un token, on demande à DRfold2 « as-tu appris la géométrie ? » via un swap d'un nucléotide.

2. LM auto-supervisé

DRfold2 entraîné sur séquences brutes d'ARN, sans labels fonctionnels. RCLM = transformer auto-encodeur (style BERT) sur l'alphabet AUGC.

3. L'architecture compte

RhoFold+ (Evoformer, conçu pour MSA) en mode séquence-seule : top-5 identique pour toute mutation. Sans MSA, il ignore l'input → prior fixe.

4. Analogie NLP

DRfold2 ≈ un BERT qui change correctement la prédiction quand on remplace « the cat sat » → « the cats sat ».
RhoFold sans MSA ≈ un modèle qui sort la même phrase quelle que soit l'entrée.
